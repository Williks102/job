# **App Name**: Domicile Emploi

## Core Features:

- Job Listing: Display available domestic jobs (housekeepers, nannies, butlers, drivers, etc.).
- Job Detail View: Show job conditions and details upon clicking an offer.
- WhatsApp Integration: Allow users to send job details via WhatsApp with a single click.
- AI Recommendation tool: AI model recommends fitting job offers based on user profile.

## Style Guidelines:

- Primary color: Soft blue (#A0CFEC) to evoke trust and cleanliness.
- Background color: Very light grey (#F0F0F0) to create a clean, minimalist backdrop.
- Accent color: Light green (#BCE29E) for interactive elements and call-to-action buttons.
- Font pairing: 'Inter' for body text (sans-serif, modern) and 'Literata' for headings (serif, literary).
- Simple, line-based icons representing different job categories (e.g., a broom for housekeepers, a baby carriage for nannies).
- Clean, grid-based layout to present job listings in an organized and easily navigable manner.
- Subtle transitions when navigating between job listings and detail views.
